# How Tos

Welcome to **How Tos**! The ultimate destination for guided tutorials that won't make you want to throw your keyboard out the window or maybe just slightly less often.

## Features

- **Blog Tutorials**: Guided, written tutorials that strive to be clearer than those Swedish furniture assembly manuals.
- **YouTube Tutorials**: Direct references to our video channel, because sometimes you just need to see someone else click the button first before you trust it.

An app to guide you to your next config hopefully without the existential dread!
